# Day 22 - Git Basics Notes

## 1. Difference between git add and git commit

git add moves changes to the staging area.

git commit permanently saves staged changes into the Git repository.

---

## 2. What is the staging area?

The staging area is a temporary place where we prepare changes before committing them.

It lets us choose which changes should be included in the next commit.

---

## 3. What does git log show?

git log displays the commit history including:

- Commit ID
- Author
- Date
- Commit message

---

## 4. What is the .git folder?

The .git folder stores all repository information including commits, branches, history and configuration.

If deleted, the directory is no longer a Git repository.

---

## 5. Working Directory vs Staging Area vs Repository

Working Directory:
Current files being edited.

Staging Area:
Prepared changes waiting to be committed.

Repository:
Permanent history of commits stored by Git.
